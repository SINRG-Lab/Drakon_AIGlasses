# Drakon — Standalone Edition

The untethered build. An on-board cellular modem lets the glasses reach the
network directly, with no companion device in the path.

Compared to the [Companion Edition](../companion/), this build adds the modem,
its antenna and RF front end, and a larger power budget. Prior cellular work
was done on a Walter dev board (ESP32-S3 + Sequans Monarch 2) rather than a
Drakon PCB, so no board has been fabricated for this edition yet.

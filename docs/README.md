# Documentation

Cross-cutting documentation. Anything specific to one board revision belongs in
that revision's own directory instead.

- [`versioning.md`](versioning.md) — edition and revision conventions
- [`specs/`](specs/) — requirements, pinouts, power budgets, mechanical drawings
- [`assembly/`](assembly/) — build and assembly instructions
- [`bring-up/`](bring-up/) — board bring-up procedures and debugging notes
